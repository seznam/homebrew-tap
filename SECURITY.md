# Security Policy

## Supported versions

Each cask in this tap tracks the latest release of its project. Only that latest release receives security fixes. Run `brew update && brew upgrade --cask <name>` before reporting an issue, and check whether it still reproduces.

| Cask | Supported version |
| --- | --- |
| `jailoc` | latest release |

## Reporting a vulnerability

Report vulnerabilities privately through the GitHub security advisories of the affected project. Do not open a public issue, pull request or discussion for a suspected vulnerability.

- `jailoc`: [report a vulnerability](https://github.com/seznam/jailoc/security/advisories/new)

If the problem is in this tap itself, for example a cask that downloads an unexpected artifact or has a wrong checksum, report it through the advisories of the project the cask belongs to.
