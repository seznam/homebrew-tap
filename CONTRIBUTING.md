# Contributing

The casks in [`Casks/`](Casks) are generated by the release pipeline of each project and are overwritten on every release. Do not change them in this repository.

- Problems with a cask (installation, checksums, caveats, platform support) belong to the source project. Open an issue or a pull request there, for example in [seznam/jailoc](https://github.com/seznam/jailoc).
- Fixes to the documents in this repository (README, license, changelog, contributing and security notes) are welcome as pull requests here.
- To add a new cask, the project must be published under [github.com/seznam](https://github.com/seznam) and configure its release pipeline to push the cask to this repository.

Security issues must not be reported publicly. See [SECURITY.md](SECURITY.md).
